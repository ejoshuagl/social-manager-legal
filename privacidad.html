Política de privacidad

Última actualización: 9 de noviembre de 2026

1. Responsable y contacto

Social Manager es una herramienta privada utilizada para gestionar contenido de redes sociales relacionado con la Página Centauros Security Cía. Ltda. Para preguntas o solicitudes relacionadas con los datos tratados mediante esta herramienta, escribe a info@centaurossecurity.com.

2. Finalidades

Social Manager permite preparar borradores, almacenar archivos multimedia, programar publicaciones, conectar cuentas autorizadas y registrar el resultado de envíos a redes sociales. No se ofrece como una plataforma de registro público.

3. Información que se procesa

  • Contenido de publicaciones: títulos, textos, fechas, horarios, redes seleccionadas y estados de publicación.
  • Fotografías o videos que se carguen voluntariamente en el sistema.
  • Datos técnicos de cuentas y Páginas autorizadas, como identificadores y permisos de acceso necesarios para publicar.
  • Credenciales de integración y tokens de acceso, almacenados en la infraestructura privada de la herramienta y utilizados exclusivamente para las funciones autorizadas.
  • Registros técnicos de operaciones y errores para diagnosticar fallos y evitar publicaciones duplicadas.

4. Uso y acceso a la información

Los datos de trabajo se guardan en el servidor propio donde se ejecutan la aplicación, PostgreSQL y n8n. El acceso se limita a personas autorizadas. La herramienta envía a las plataformas conectadas el contenido que el administrador decide publicar; dicho contenido pasa a estar sujeto también a las políticas de las plataformas correspondientes.

5. Servicios externos

La publicación en Facebook e Instagram, cuando esté configurada, utiliza los servicios y API de Meta. Las demás plataformas se utilizarán únicamente cuando se configuren y autoricen sus integraciones. Estas páginas informativas se alojan en GitHub Pages; GitHub puede tratar datos técnicos de visita, como direcciones IP, de acuerdo con sus propias políticas.

6. Conservación

Los borradores, archivos y registros se conservan en la infraestructura privada mientras resulten necesarios para la operación o hasta su eliminación por el administrador, sin perjuicio de obligaciones legales aplicables. La eliminación de contenido dentro de Social Manager no garantiza la eliminación automática de publicaciones o copias que ya existan en plataformas externas.

7. Seguridad

Se utilizan controles de autenticación y acceso privado para el panel y las integraciones. Ningún sistema puede garantizar seguridad absoluta. Los tokens y contraseñas no deben compartirse mediante repositorios públicos, capturas ni mensajes.

8. Solicitudes y derechos

Para consultar, corregir o solicitar la eliminación de información tratada por Social Manager, escribe a info@centaurossecurity.com. Se podrá solicitar información razonable para verificar la identidad o autoridad de quien presenta la solicitud. Consulta también las instrucciones para eliminar datos.

9. Cambios

Esta política podrá actualizarse si cambia el funcionamiento del sistema o sus integraciones. La versión vigente estará disponible en esta dirección.
